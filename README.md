# Frank’s Apps — release downloads

Public IPAs for [LTH and YouTube LTH](https://apps.frank-hernandez.com).

Add `https://apps.frank-hernandez.com/source.json` to a signing app that accepts AltStore-style repositories, or download an IPA from Releases and import it into your signer. A signing account or certificate is required. Update existing installations with the same account to preserve app data.

The latest releases are [LTH 1.8.2 (18)](https://github.com/fkhernandez/frank-apps-releases/releases/tag/lth-v1.8.2) and YouTube LTH 21.41.5, build 21.41.7, with [YTKACE frank.14](https://github.com/fkhernandez/frank-apps-releases/releases/tag/youtube-lth-frank.14). Each release includes SHA-256 checksums. The website and signing-app feed include LTH 1.8.2 (18). The catalog records the actual versions, minimum iOS, byte sizes and permissions. App development repositories remain private.

YouTube is by Google. YTKACE is by [itzzace and contributors](https://github.com/itzzace/ytkace); these are Frank’s personal builds. Its MIT license and third-party notices accompany each YouTube release. YouTube frank.14 includes profile-avatar, icon-only download-tab and initial Shorts-control fixes while retaining LTH branding. LTH 1.8.2 corrects search filter overlap and list spacing. Physical-device installation and YouTube rendering remain unverified; the earlier phone-wide freeze is not confirmed fixed.
